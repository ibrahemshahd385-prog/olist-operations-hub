# Olist Operations Hub (live demo)

A prototype of an internal operations system that HVIA could build for Olist:
orders and NF-e invoices, delivery-promise and late-risk models, seller health
scores, and review intelligence. Built on the public Olist dataset (2016-2018).

Code and documentation: https://github.com/ibrahemshahd385-prog/olist-operations-hub

Orders you register here are a demo: they disappear when the Space restarts.
